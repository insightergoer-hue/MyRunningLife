# 身体评分锚点（1 = 很好，10 = 很差）

> 2026-11-16 起用 · 先用于**小腿**；膝/深肌/脚底可同理套。  
> 报的是**此刻**（走动/下楼后的真实感觉），不是「我还能不能硬跑」。

## 小腿（含一般酸痛；正后方深肌另说时请点名）

| 分 | 生活里像什么 | 训练含义 |
|----|--------------|----------|
| **1** | 完全无感，和下楼无关 | 可按计划 |
| **2** | 想起来才有一点点紧，走几步就忘 | 可按计划 |
| **3** | 下楼/起身时有轻酸，热开后基本消失 | 可训；仰山/长课注意下坡多走 |
| **4** | 走路一直能感到酸胀，但不影响步态；慢跑会更明显 | **减量**；插入走；避免大下坡课 |
| **5** | 明显酸胀，下楼不舒服，坐久站起要缓一缓；轻松跑也会一直提醒你 | **不上仰山/半马**；休或纯走；最多超短超轻松 |
| **6** | 酸得很清楚，平路慢跑也别扭；你知道「今天不适合加量」 | **休或纯走**；不批长课（今早闸） |
| **7** | 锐痛或明显跛行倾向；不敢正常下楼；跑几步就想停 | **停跑收工** |
| **8** | 走路也疼得改步态；触摸/大扭脚会诱发 | 停训 + 观察；勿「跑开」 |
| **9–10** | 几乎不能正常走，或疑似急性拉伤 | 停训；需要时就医 |

### 和教练闸门对齐

| 分 | 闸 |
|----|-----|
| 1–2 | 按课表 |
| 3–4 | 减量 / 多走 |
| **5–6** | 不上山、不长跑；休或纯走（≤6–8 km 超轻松仅作勉强上限） |
| **≥7** | 立刻停 |

### 怎么选分（避免纠结）

1. 先问：**下楼酸不酸？** 不明显 → 多半 ≤3；明显且持续 → 至少 4–5  
2. 再问：**轻松慢跑会不会全程提醒你？** 会 → 至少 5–6  
3. 再问：**有没有锐痛、跛、扭一下就炸？** 有 → ≥7，不要报 5「撑着」  
4. **酸 ≠ 伤**：DOMS 常在 4–6；锐痛/深压痛/无力往上报  
5. **正后方深肌**（旧「踝前」那块）：有症状时单独报，仍用上表；≥4 多走，≥7 停  
6. **快速自测**：双脚踮脚 5–8 次——无痛偏 1–3；明显疼但能走完偏 **4–5**；单脚踮不了/锐痛偏 **≥6–7**

### 今早对照 / 修正规则

- 「走路没感觉，但按压比较明显」→ 功能分多落在 **3（有时 4）**：属于触痛型酸，不是 5–6 的「走动/慢跑全程提醒」。
- 报分优先看 **走路 / 下楼 / 慢跑时有没有提醒你**；按压痛单独注明即可（「触痛明显」）。
- **不要因为想跑故意低报**；也不要把「按着疼」自动等同 6–7。

### 2026-11-16 改报

1. 走路无感 · 按压明显 → 曾改记 **~3**  
2. **追加：踮脚小腿会疼** → 负重蹬伸仍痛，功能分上调至 **~4–5**（跑/爬会反复用到踮脚同款动作）  
3. 课表再收：不批 12–16 长；休 / 纯走 / 或 ≤6–8 km 超轻松。
